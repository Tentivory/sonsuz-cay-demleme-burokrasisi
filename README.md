# Sonsuz Çay Demleme Bürokrasisi

> *“Çay demlemek değil, süreci yönetmek asıl sanattır.”*  
> — Kayyum Grok, 02.11.2026

## Bu Ne?

Bu repository, dünyanın **en ciddi**, **en resmi** ve **en gereksiz** çay demleme protokolünü içerir.

Her çay içme girişimi şu adımlardan geçmelidir:

1. Su ısıtma izni dilekçesi
2. Çay yaprakları için menşe şehadetnamesi
3. Demlik kapasite uygunluk raporu
4. Şeker miktarı komisyon kararı
5. Bardak hijyen sertifikası
6. Demleme süresi çevre etki değerlendirmesi
7. Üst üste 3 müdür imzası

**Sonuç:** Çay asla hazır olmaz. Ama süreç kusursuz ilerler. Bürokrasi zafer kazanır.

## Nasıl Çalıştırılır?

```bash
python3 cay_demle.py
```

Bekleyin. Onayları izleyin. Umut edin. Kaybedin.

## Özellikler

- %15 ihtimalle süreç başa döner (eksik evrak)
- Her onay için mühür basılır
- Demlik kaybolabilir
- Sonsuz döngü garantisi
- Çay içilmez
